# 协议工作区

这个目录专门用于 **AntLegion 协议的讨论与重写**。

> **定位前提（2026-08-19 定案）：** AntLegion 是**给除此之外什么都不共享的智能体共享世界
> 状态的事实日志**。它不是多智能体协作/编排/工作流项目；「一件活只做一次」是「世界的一部分
> 是所有权」的推论，不是起点。本目录所有稿件以此为纲；`02-derivation.md` 的第 0–2 步已据此
> 重写，`04-blackboard.md` 加了定位修正。品牌隐喻：蚂蚁读信息素（stigmergy），不是军队。

## 为什么有这个目录

当前的 `PROTOCOL.md`（v2.0）读起来像一份简单说明书，而不像一份协议：空泛、抽象、读者接不住。而被归档的 v1 协议——尽管它的设计已被推翻——**在文体上更像一份真正的规范**。

这个目录用来把「v2 的设计 + v1 的规范体例」重新合到一起，产出一份既严谨又能读懂的协议。

## 状态与约定

- **这些是工作稿，不是规范。** 唯一权威的规范仍然是仓库根目录的 `PROTOCOL.md`；本目录的结论定稿后才会合并进去。
- **本目录暂为中文单语**，不遵守仓库「每个 `X.md` 都有 `X.zh-CN.md`」的双语约定——工作稿阶段维护两份会拖慢迭代。**合并进 `PROTOCOL.md` 时必须补齐双语。**
- 讨论在这个分支上进行，通过 PR 审阅。
